# PRODIGY_DS_04 — Sentiment Analysis & Visualization

## Task Overview
This task focuses on analyzing and visualizing sentiment patterns in social media data to understand public opinion and attitudes toward a specific topic or brand. The objective is to transform unstructured text into structured sentiment insights and present them through clear and interpretable visualizations.

## Objective
1. Analyze sentiment distribution across social media content
2. Visualize public opinion using categorical and proportional charts
3. Identify trends and dominant sentiment patterns
4. Highlight common themes contributing to positive and negative sentiment

## Tools & Technologies
* Python Jupyter notebook
* Tableau
* Microsoft Excel
* GitHub
* Visualizations Created :Bar Chart — Distribution of sentiment categories, Pie Chart — Proportion of positive, negative, and neutral sentiment

## Exploratory Analysis
- Examined overall sentiment balance to assess public opinion
- Analyzed trends to identify periods of increased positive or negative sentiment
- Identified frequently occurring keywords associated with negative feedback

## Key Insights
- The dataset shows a dominant sentiment category, indicating overall public perception toward the selected topic.

- Negative sentiment is primarily associated with recurring keywords related to user experience and service issues.

- Sentiment trends reveal noticeable fluctuations over time, suggesting the influence of external events or announcements.

## Conclusion

This task demonstrates how sentiment analysis and visualization techniques can be used to convert large volumes of unstructured social media data into meaningful insights about public opinion and behavioral trends.
